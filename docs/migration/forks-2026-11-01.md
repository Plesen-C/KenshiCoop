## Upstream review

- Experimental co-op for Kenshi 1.0.65 Steam: C++ DLL through RE_Kenshi/KenshiLib, ENet/UDP or Steam P2P. Original target: two players. Host owns the world; each player owns a squad. Replicates NPCs, combat, inventory, construction, shared money and saves. [README](https://github.com/nhoral/KenshiCoop/blob/main/README.md).
- Last main commit:5a761e19,2026-08-10 19:51 UTC. Latest release [v0.51](https://github.com/nhoral/KenshiCoop/releases/tag/v0.51):2026-08-10 19:52 UTC, wire protocol 55. The release explicitly requires matching versions: even v0.50/v0.51 cannot connect. [Commit](https://github.com/nhoral/KenshiCoop/commit/5a761e19a4184b42315e96ea7e92e3c1403d54db).
- Modules are core/game/net/sync/test, with mutations on the game thread. Protocol tests, simulator, Steam-tunnel tests and two-client scenarios exist; they were not executed in this review. [Plugin.cpp](https://github.com/nhoral/KenshiCoop/blob/main/src/plugin/Plugin.cpp), [verify.ps1](https://github.com/nhoral/KenshiCoop/blob/main/scripts/verify.ps1).
- Build requires Windows, Visual C++ 2010/v100 x64, KenshiLib and patched ENet. docs/BUILD_SETUP.md redirects to resources/BUILD_SETUP.md, absent from the reviewed tree. API reference retains explicitly marked historical sections for a removed transport stack. [Project](https://github.com/nhoral/KenshiCoop/blob/main/src/plugin/KenshiCoop.vcxproj), [build document](https://github.com/nhoral/KenshiCoop/blob/main/docs/BUILD_SETUP.md), [API reference](https://github.com/nhoral/KenshiCoop/blob/main/docs/API_REFERENCE.md).
