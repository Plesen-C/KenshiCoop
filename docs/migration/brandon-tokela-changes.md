## Доказанные несовместимости

1. **Wire collisions.** Brandon: 50 SquadName, 51 FactionRename, 52 FactionName, 53 Jobs. Atimal: 50 ProdIntent, 51 DoorIntent, 52 FurnIntent, 53 BuildIntent, 54 InvSaveFence, 55 Bounty, 56 ModList, 57 StoreAdd. Savas: 52 VendorDelta, 53 VendorCash и отдельный JoinState. Равные version numbers разных форков не означают совместимость. Нужны новая protocol identity, уникальная таблица tags, проверки wire sizes/limits и отказ чужим builds. Brandon public 72/private NET_DIAG 73; Savas 65; atimal 68; Tokela 59.
2. **Session topology.** Brandon — 4 players, Savas — 8, Tokela/atimal — 2. Owner checks, stale guards, admission, roster, tab ownership, fences, ACK, trading locks и Steam lobbies должны работать отдельно для каждого player/session. Один глобальный friend state нельзя перенести на 8 игроков без адаптации.
3. **Inventory writers.** StoreAdd mint, optimistic cross-owner transfer, strict cursor reservations, exact stock layout, vendor deltas и trader handover могут учитывать одно действие несколько раз. Нужны единый operation ID и один механизм settlement; сначала identity, затем writers.
4. **World authority.** Tokela/atimal включали cellAuth по умолчанию, но свежий Tokela b3bd37b возвращает default off после полевых сбоев. Savas squad split/recruit patches и Brandon NPC mirror опираются на разные признаки copy/owner. До доказательства корректной миграции authority на границах клеток предлагается host world authority, собственные player squads и cellAuth opt-in.
5. **UI/update.** NativeCoopUI ABI с paired core/UI update, MyGUI F2 и main-menu lobby — альтернативные frontend реализации. Три обработчика input/focus/lobby callbacks одновременно не нужны. Имена, URLs, Workshop item и manifests следует настроить для итогового проекта.
6. **Saves.** READY для конкретной загрузки, inventory fence, metadata/jobs flush, atomic staging, compression, pause cause и backups образуют одну транзакцию. Три реализации SaveXfer нельзя сливать простым выбором файлов.
7. **Build/ABI.** Tokela закрепляет KenshiLib 0.3.0; Brandon имеет header fix для 0.4.0. ENet internals с окном 512 KB и GNS migration kotetsyy требуют разных transport adapters. Игровые исправления можно объединять независимо от выбора транспорта, но прямые ENet вызовы нельзя переносить в GNS.
